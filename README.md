# GP6 | Krabi Model

เว็บไซต์เผยแพร่ผลงานกลุ่ม GP6 นบส.1 รุ่นที่ 104 โดยใช้รายงาน GP6_04092026.docx เป็นข้อมูลหลัก

## เริ่มใช้งาน

ต้องมี Node.js 22.13 ขึ้นไป

```sh
npm install
npm run dev
```

สร้างไฟล์สำหรับเผยแพร่ด้วย `npm run build`

## แก้ไขเนื้อหา

- `data/site.ts`: ข้อเสนอ 4 นโยบาย ตัวเลขหน้าแรก และอาจารย์ที่ปรึกษา
- `data/report.json`: สมาชิก ตำแหน่ง หน่วยงาน บทสรุป และบรรณานุกรมจากรายงาน
- `components/explorers.tsx`: หมวดและตัวชี้วัด Dashboard
- `public/documents/GP6_04092026.docx`: รายงานดาวน์โหลด
- `public/ocean.png`: ภาพสร้างสรรค์ 3D สำหรับส่วนเปิดเรื่อง
- `app/globals.css`: สี ฟอนต์ รูปแบบ responsive และ reduced motion
- `app/team/page.tsx`: แทนที่ UserRound ด้วยภาพสมาชิกจริงเมื่อมีภาพและยืนยันตัวบุคคลแล้ว

หน้าเว็บไซต์: `/`, `/team`, `/documents`, `/policies/smart-coast`, `/policies/blue-value`, `/policies/blue-skills`, `/policies/high-value-tourism`

## ข้อมูลและภาพ

ตัวเลขใช้ปีฐานที่ระบุในรายงาน ไม่ใช่ข้อมูลเรียลไทม์ ระบบ Krabi Marine Link, Blue Economy Dashboard และ timeline เป็นข้อเสนอ ไม่ใช่สถานะดำเนินงานจริง ตัวชี้วัดที่ไม่มีค่ารายงานจะแสดงสถานะไม่มีข้อมูล

ภาพเปิดเรื่องเป็นภาพสร้างสรรค์ที่สร้างด้วย AI ในสไตล์ 3D มีการเคลื่อนไหวอย่างนุ่มนวลและปุ่มหยุด ภาพเป็น raster เพื่อให้โหลดง่ายและแสดงผลได้โดยไม่ต้องใช้ WebGL ไม่ใช่แผนที่ภูมิศาสตร์ ภาพบุคคลและภาพกิจกรรมยังไม่แสดงเนื่องจากไม่มีภาพที่ยืนยันตัวบุคคลได้
