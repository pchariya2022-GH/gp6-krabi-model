# GP6 | Krabi Model

เว็บไซต์เผยแพร่ผลงานกลุ่ม GP6 นบส.1 รุ่นที่ 104 โดยใช้รายงานกระบี่โมเดลของกลุ่ม GP6 เป็นข้อมูลหลัก และเผยแพร่ไฟล์ GP6_04092026.pdf สำหรับดาวน์โหลด

เว็บไซต์ที่เผยแพร่: https://gp6-krabi-model.potchara-a.chatgpt.site

## เริ่มใช้งาน

ต้องมี Node.js 22.13 ขึ้นไป

```sh
npm install
npm run dev
```

สร้างไฟล์สำหรับเผยแพร่ด้วย `npm run build`

## แก้ไขเนื้อหา

- `data/site.ts`: ข้อเสนอ 4 นโยบาย ตัวเลขหน้าแรก และอาจารย์ที่ปรึกษา
- `data/report.json`: สมาชิก ตำแหน่ง หน่วยงาน บทสรุป และบรรณานุกรมจากรายงาน
- `components/explorers.tsx`: หมวดและตัวชี้วัด Dashboard
- `public/documents/GP6_04092026.pdf`: รายงานดาวน์โหลด
- `public/ocean.png`: ภาพสร้างสรรค์ 3D สำหรับส่วนเปิดเรื่อง
- `app/globals.css`: สี ฟอนต์ รูปแบบ responsive และ reduced motion
- `public/images/gp6-members.jpg`: ภาพสมาชิกต้นฉบับที่ผู้ใช้แนบ แสดงรายบุคคลด้วย CSS ตามพิกัดใน `data/report.json`

หน้าเว็บไซต์: `/`, `/team`, `/documents`, `/policies/smart-coast`, `/policies/blue-value`, `/policies/blue-skills`, `/policies/high-value-tourism`

## ข้อมูลและภาพ

ตัวเลขใช้ปีฐานที่ระบุในรายงาน ไม่ใช่ข้อมูลเรียลไทม์ ระบบ Krabi Marine Link, Blue Economy Dashboard และ timeline เป็นข้อเสนอ ไม่ใช่สถานะดำเนินงานจริง ตัวชี้วัดที่ไม่มีค่ารายงานจะแสดงสถานะไม่มีข้อมูล

ภาพเปิดเรื่องเป็นภาพสร้างสรรค์ที่สร้างด้วย AI ในสไตล์ 3D มีการเคลื่อนไหวอย่างนุ่มนวลและปุ่มหยุด ภาพเป็น raster เพื่อให้โหลดง่ายและแสดงผลได้โดยไม่ต้องใช้ WebGL ไม่ใช่แผนที่ภูมิศาสตร์ ภาพสมาชิกใช้แผ่น Core Team GP6 ที่ผู้ใช้แนบ โดยจับคู่จากรหัสสมาชิกที่พิมพ์บนภาพและใช้ CSS แสดงเฉพาะบริเวณรูปแต่ละคน ไม่ปรับแต่งใบหน้า
